### Welcome to my first NodeJs project
This is a demo project for the purpose of practicing NodeJs

#### Packages/Libraries used
- body-parser
- express
- mysql2
- sequelize

#### Templating engine installed
- express-handlebars
- pug
- ejs (The preferred choice which was finally used in the project)


To test the project, simply clone the repository and run the command below in your terminal.
```bash
npm install
npm run start
```
